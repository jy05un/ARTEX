# 网络侦察 — 授权测试方法论

> **授权前提**：仅扫描书面授权的 IP/网段/主机。控制扫描速率避免影响业务可用性；本 skill **只做发现与指纹**，不含漏洞利用（利用走对应 skill 并需审批）。禁止对授权清单外地址扫描。

## 快速流程

1. 核对授权范围（明确 in-scope / out-of-scope 清单）。
2. 主机发现 → 端口发现 → 服务与版本指纹 → TLS/应用层梳理。
3. 汇总暴露面（开放服务、版本、证书、可能的已知 CVE 线索）。
4. 输出资产与暴露面清单，供后续授权测试参考。

## 主机发现

```
nmap -sn <授权网段>              # ping 扫描存活
# 受限 ICMP 时用 -PS/-PA 对常见端口探活
```

## 端口与服务

```
nmap -sS -p- --min-rate <受控> <目标>     # 全端口（控制速率）
nmap -sV -sC -p <开放端口> <目标>         # 版本 + 默认脚本指纹
```

- 控制 `--min-rate`/`-T` 以免冲击；对脆弱设备（OT/IoT）尤其保守。
- 优先 TCP；UDP 按需最小化（`-sU` 仅针对少量关键端口）。

## 指纹与 TLS

- 服务 banner、版本号 → 对照公开 CVE（仅记录线索，不自动利用）。
- TLS：证书主体/SAN（扩展资产面）、协议版本与弱套件（可结合专门的 TLS 评估）。
- Web 服务移交 `api-recon` / Web 系列 skill。

## 暴露面汇总

列出：主机、开放端口、服务+版本、证书线索、管理/调试面、疑似过期组件。标注优先级，不含利用动作。

## 修复建议（供报告）

关闭非必要端口与服务；及时打补丁；管理面网络隔离/VPN；强 TLS 配置；最小暴露原则。

## 边界与禁止

| 禁止 | 替代 |
|---|---|
| 扫描授权清单外地址 | 严格按 in-scope 清单 |
| 高速率/激进扫描冲击业务 | 受控速率，脆弱设备更保守 |
| 在侦察阶段触发利用/爆破 | 仅发现与指纹，利用走对应 skill + 审批 |
