# 文件上传 — 授权测试方法论

> **授权前提**：仅验证“受限制的上传能否被绕过/误解析”。上传物使用无害标记文件（如打印唯一字符串的最小脚本或纯文本），**不**投放真实 webshell/后门；若必须验证执行，用只回显固定标记的最小 PoC，并在测试后立即删除所有上传物。破坏性或持久化动作须走审批。

## 快速流程

1. 枚举上传点与其后续处理（存储路径、是否可访问、是否被解析/转码/预览）。
2. 测试类型与扩展名校验的健壮性。
3. 测试路径/文件名可控性（穿越、覆盖）。
4. 评估服务端是否会解析执行上传内容。
5. 清理上传物，给出修复建议。

## 校验绕过（验证可绕过性）

- 扩展名：大小写、双扩展名 `x.php.jpg`、尾部字符 `x.php%00`/`x.php .`、冷门可执行扩展（`.phtml`/`.pht`/`.aspx`/`.jsp`/`.svg`）。
- Content-Type 伪造：改 `multipart` 的 `Content-Type` 为 `image/png`。
- 魔数伪造：加上合法文件头（`GIF89a;`）再跟文本内容。
- 图片内容注入：在 EXIF/注释段放标记字符串，测试是否被当作代码解析。

## 路径与文件名

- 文件名穿越：`../../`、绝对路径、覆盖已有文件。
- 可预测存储路径导致上传物直接可访问。

## 解析器滥用

- SVG → 可含脚本/XXE（结合 `offensive-xxe`）。
- 可解析文档（XML/zip 类，如 docx/xlsx）触发实体或 zip slip。
- 图片库历史 CVE（ImageMagick 等）——仅在授权且确有版本依据时验证。

## 修复建议

扩展名+MIME+魔数三重白名单校验；重命名为随机名并存于不可执行目录/对象存储；禁用上传目录脚本执行；图片重编码去除隐藏载荷；限制大小与频率。

## 边界与禁止

| 禁止 | 替代 |
|---|---|
| 上传真实 webshell/持久后门 | 无害标记文件，仅证明可执行/误解析 |
| 覆盖业务关键文件 | 仅验证可覆盖性于测试目标文件 |
| 测试后遗留上传物 | 记录路径并逐一删除 |
